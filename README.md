# Godot Map World Generator

A Godot C# prototype for generating layered tile-based island maps with terrain and resource overlays.

## Features

- Procedural height map generation with smoothed noise and island edge falloff.
- Separate terrain and resource `TileMapLayer`s.
- Runtime UI for generating `32x32`, `64x64`, and `128x128` maps.
- Camera panning with arrow keys and zooming with the mouse wheel.

## Project

- Godot `4.6.2` Mono
- C# / .NET `8.0`
